Content Analysis 障害発生時に取得する基本情報

Content Analysis で障害が発生した場合、Content Analysis の GUI にログインし、以下の情報を取得します。

1. Content Analysis のシステム情報

Utilities > System Information を開きます。表示された内容をすべてコピーし、テキストエディタなどに貼り付けて保存します。

2. Troubleshooting Log

Utilities > Troubleshooting を開きます。取得手順は以下の通りです。

1) Create troubleshooting log をクリックします。2) Select all cores をクリックしてすべて選択します。
3) Create をクリックします。
4) 画面を再読み込みし、Status が In Progress から Completed になることを確認します。
5) Download ボタンからログをダウンロードします。

3. Configuration ファイル

Utilities > Configuration を開きます。Get Configuration をクリックし、設定ファイルを取得します。

https://Proxy-IP:8082/sysinfo最後までロードされることを確認し、右クリックなど"名前を付けて保存"でテキストファイルに保存してください

Eventlog
https://Proxy-IP:8082/Eventlog/StatisticsDownload
.. をクリックし events.logというファイル名のまま保存してください

【事象の発生から24時間以上】

Snapshot
https://Proxy-IP:8082/Diagnostics/Snapshot2種類あります。それぞれのリンクをクリックし、ファイルを保存してください。

Snapshot sysinfo: Enabled (/sysinfo) download allSnapshot
sysinfo_stats: Enabled (/sysinfo-stats) download all

事象によっては 24時間未満でも Snapshotが必要となります。
